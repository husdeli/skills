# design-doc

The rules live in one shared skill. This entry point points at it.

Read `../../skills/design-doc/SKILL.md` completely before you write or update a design doc, and follow every rule in it.
Read `../../skills/feature/SKILL.md` too: it says which folder the doc goes in, and a doc that belongs to a feature never opens that feature as a side effect.
Read every reference that file requires, and resolve each path against `../../skills/design-doc/`.
